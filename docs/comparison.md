# Подход к сравнению конфигураций

Экспериментальная часть ВКР должна показать, что метачарт снижает объём повторяющейся конфигурации и уменьшает число файлов, которые нужно сопровождать при изменении многосервисного приложения.

## Сравниваемые варианты

1. Ручное описание Kubernetes-манифестов для каждого сервиса.
2. Описание тех же сервисов через единую структуру `values.yaml` и шаблоны Helm.

## Метрики

Для сравнения используются следующие показатели:

- количество значимых строк YAML;
- количество повторяющихся блоков `metadata`, `selector`, `ports`, `resources`, `env`;
- количество файлов, изменяемых при добавлении нового сервиса;
- количество файлов, изменяемых при переходе между окружениями `dev`, `stage`, `prod`.

## Ожидаемый результат

Ожидается, что применение Helm-метачарта снизит объём повторяющейся конфигурации не менее чем на 30% по сравнению с ручным описанием Kubernetes-манифестов для аналогичного набора сервисов.

## Команда подсчёта строк

```bash
python scripts/count_yaml_lines.py baseline/manual-k8s values.yaml values-dev.yaml values-stage.yaml values-prod.yaml templates
```
